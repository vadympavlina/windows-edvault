# Контроль якості · windows-edvault

Навчальний емулятор Windows 11: Провідник, командний рядок, Блокнот, Диспетчер завдань, мережа, роутер, брандмауер.
Статична сторінка, ES-модулі, без збирання. Стан у `localStorage['edvault-windows']`. Інтерфейс українською, без емодзі.
Темний режим для цього інструмента не робимо (рішення власника), решта правил `CLAUDE.md` діє.

## 1. Перед змінами
- Нові програми додавай у `sys.open` (`main.js`); великі модулі підвантажуй ліниво через `LAZY`.
- Імена файлів, вміст і введений текст завжди екрануй (`esc`), у `innerHTML` лише власна розмітка.
- Порівняння імен роби через спільний `lc` з `fs.js` (кешований), не через `toLocaleLowerCase` напряму.

## 2. Після змін, обов'язково
| Що | Команда |
| --- | --- |
| Модульні тести | `npm test` |
| Браузерні тести | `PLAYWRIGHT_MODULE=… npm run test:e2e` |
| Список модулів для паралельного завантаження | `npm run build`, перевірка `npm run audit:build` |
| XSS: імена, вміст, команди, адреси | `npm run audit:xss` |
| Командний рядок: 6000 випадкових команд | `npm run audit:fuzz` |
| Доступність (axe) | `npm run audit:a11y` |
| Клавіатура, пастка фокусу в діалогах | `npm run audit:keyboard` |
| Швидкість, зовнішні запити, 2000 файлів | `npm run audit:perf` |

## 3. Правила
- Жодних зовнішніх запитів: шрифти лежать у `windowsemu/fonts/`, діє CSP (без вбудованих скриптів).
- Діалоги через `dialog`/`modal` з `ui.js` (пастка фокусу, Esc, Enter).
- `<main>` лише один (`#desk`); навігаційним блокам додавай `aria-label`.
- Програма, що впала, не валить систему: відкриття йде через обгортку `sys.open`.
- Кольори беруть зі змінних `:root`, нові жорсткі кольори не додавай без потреби.

## 4. Звіт
Коротко: що змінено, які перевірки пройдено, що не вдалося перевірити.
