# Перевірка веб-інтерфейсу

Правила взято з [vercel-labs/web-interface-guidelines](https://github.com/vercel-labs/web-interface-guidelines)
(MIT, Vercel Labs), версія `434b7f9`, і **адаптовано** до цього проєкту: без React-частин, з українською типографікою
й текстами. Нічого не підвантажується з інтернету: правила лежать тут, і лише змінюються в нашому репозиторії.

Прочитай вказані файли (або запитай, які), перевір за правилами нижче. Висновок: коротко, групуй за файлами у форматі
`файл:рядок — проблема`. Якщо все добре, пиши `✓ без зауважень`. Без вступу й пояснень, якщо виправлення очевидне.

## Правила

### Доступність
- Кнопки лише з іконкою мають `aria-label` або видимий текст у підписі
- Елементи форм мають `<label>` або `aria-label` (також `<select>`)
- `<button>` для дій, `<a href>` для переходів (не `<div onclick>`)
- Зображення з `alt` (порожній `alt=""` для декоративних), декоративні іконки `aria-hidden="true"`
- Нові тексти, що з'являються самі (тости, помилки), мають `aria-live="polite"`
- Спочатку семантичний HTML, потім ARIA: `role="tablist"` потребує дітей `role="tab"`, `role="meter"` потребує імені
- Заголовки по порядку `h1`–`h6`; є посилання «Перейти до змісту»
- Прокручувані області доступні з клавіатури (`tabindex="0"`)
- Жодної інформації лише кольором (стан додатково текстом чи іконкою)

### Фокус
- Кожен інтерактивний елемент має видимий `:focus-visible`
- Ніколи `outline: none` без заміни
- Липкі шапки й підвали не перекривають елемент у фокусі
- Модальні вікна тримають фокус і закриваються Esc, повертаючи фокус

### Форми
- Поля мають змістовні `name`, правильний `type`/`inputmode`; не блокувати вставку
- Помилки поруч із полем; фокус на першому полі з помилкою
- Підказки в `placeholder` закінчуються `…` і показують приклад
- Попереджати про втрату незбережених змін; руйнівні дії мають підтвердження або «Скасувати»

### Анімація
- Поважати `prefers-reduced-motion`
- Анімувати лише `transform`/`opacity`; ніколи `transition: all`
- Анімація має бути переривчастою; автозапуск понад 5 с має кнопку паузи

### Типографіка
- `…` замість `...`; українські лапки `«»` замість прямих `"`; тире `—`
- Нерозривні пропуски між числом і одиницею (`10&nbsp;МБ`, `150&nbsp;тис.&nbsp;₴`)
- `font-variant-numeric: tabular-nums` для стовпців чисел
- Заголовки: `text-wrap: balance`; Рядки до ~75 символів

### Довгий вміст і порожні стани
- Контейнери витримують дуже довгий текст (`overflow-wrap`, `min-width: 0` у flex/grid, `line-clamp`)
- Порожній стан має пояснення й дію, а не порожнє місце
- Користувацький текст: короткий, середній, дуже довгий (перевір усі три)

### Зображення
- `<img>` з `width` і `height` (без стрибків макета); нижче першого екрана `loading="lazy"`

### Продуктивність
- Великі списки (>50 елементів): `content-visibility: auto` або віртуалізація
- Не читати розміри (`getBoundingClientRect`, `offsetHeight`) у циклах відмальовування; групувати читання й запис DOM
- Критичні шрифти з `<link rel="preload" as="font" crossorigin>` і `font-display: swap`
- Модулі ES: `modulepreload` для глибоких ланцюжків імпорту; жодного зайвого JS на першому екрані

### Дотик і взаємодія
- `touch-action: manipulation`; цілі натискання ≥ 44×44 px (на ПК допускається 32)
- `overscroll-behavior: contain` у модальних вікнах і висувних панелях
- Перетягування має альтернативу кліком і клавіатурою
- `autofocus` лише для одного головного поля й лише на ПК

### Безпека (обов'язково для цього проєкту)
- Кожен рядок користувача чи зі збереження в HTML-шаблоні проходить `esc()`: імена, назви, нотатки, відповіді вправ, імена файлів, дані з імпортованого `.edvault`
- Нічого з файлу збереження не вставляється через `innerHTML` без екранування (перевір: `npm run audit:xss`)
- Збережений стан ніколи не припускається коректним: типи полів перевіряються при завантаженні (перевір: `npm run audit:fuzz`)

### Тема й верстка
- `color-scheme` і `<meta name="theme-color">` відповідають фону сторінки (темна тема за правилами CLAUDE.md, якщо вона є в інструмента)
- Макет на flex/grid, не на вимірюваннях у JS; не допускати горизонтальної прокрутки на 390, 768, 1024, 1366 px

### Тексти (українська)
- Активний стан і звернення «ви» без роду (жодних «зробив/зробила»); без емодзі
- Кнопка називає дію: «Зберегти варіант», а не «Далі» чи «Готово» без потреби
- Помилка каже, що сталося й що робити далі
- Одне слово для одного поняття: вправа, етап, розділ (не змішувати «завдання/справа/крок»)
- Числа цифрами: «8 вправ», а не «вісім»
- Речення, а не Title Case, у заголовках і кнопках

### Антипатерни (позначай)
- `user-scalable=no` / `maximum-scale=1`
- `transition: all`
- `outline: none` без `:focus-visible`
- `<div>`/`<span>` з обробником кліку замість `<button>`
- Зображення без розмірів
- Поле без підпису; кнопка-іконка без імені
- Жорстко задані формати дат і чисел замість `Intl.*`
- Значення кольорів, шрифтів, радіусів, тіней, `z-index` напряму замість змінних `:root`
- Жест (перетягування, свайп) без альтернативи кліком
