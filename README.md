# Емулятор Windows · Edvault

Навчальний емулятор Windows у браузері: Провідник, командний рядок, Блокнот, Диспетчер завдань, мережа, роутер, брандмауер, антивірус. Вхід на екрані блокування: `admin` / `admin`. На телефоні показує, що потрібен комп'ютер чи планшет.

Статична сторінка без збирання: `index.html` + `windowsemu/`.

| Що | Де |
| --- | --- |
| Сторінка | `index.html` |
| Код емулятора (ES-модулі) | `windowsemu/js/` |
| Стилі й шпалери | `windowsemu/app.css`, `windowsemu/*.jpg` |
| Значки | `icons/` |

## Запуск і тести

```
npm start                # http://localhost:8080
npm test                 # модульні тести
npm run test:e2e         # браузерні тести (потрібен Playwright)
npm run test:e2e -- winfw   # лише ті, у назві яких є «winfw»
```

Правила оформлення (темний режим, мова інтерфейсу) — у `CLAUDE.md`.

## Походження

Емулятор винесено з репозиторію `edvault-emulators`.
